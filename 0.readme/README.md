# examenfinaldatabricks
El presente trabajo consta en las siguientes fases:
1. Fase preparación de ambientes: Se crean todos los DDL
2. Fase Bronze-Esquema Medallion: Se cargan las tablas
3. Fase Silver-Esquema Medallion: Se modifican las tablas para lo que se necesita
4. Fase Gold-Esquema Medallion: Es la última capa donde se prepara para subir al PBIX
5. Fase Grants: Se ofrecen permisos a los usuarios
6. Fase Delta Sharing: Se genera un secreto para poder conectar al PowerBI
